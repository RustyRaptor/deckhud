# deckhud

On-screen HUD for Steam Input in **KDE Plasma (Wayland) Desktop Mode** on the Steam Deck:

- **Radial menu HUD**: see which radial item you're selecting, as in Game Mode.
- **Key-chord toasts**: see which keys a button just sent (`[R4] Ctrl + Shift + T`).
- **Layer cheat sheet**: see what every control does in the current action layer.

Transparent, click-through overlays tinted with your KDE accent colour.
